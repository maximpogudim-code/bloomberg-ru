# Bloomberg Terminal на русском

Bloomberg Terminal RU — это программа, которая показывает финансовые новости и данные с Bloomberg.com на русском языке. Новости переводятся автоматически, котировки обновляются в реальном времени. Программа запускается на вашем компьютере и открывается в браузере — никаких платных подписок и регистраций не нужно.

---

## Как запустить (Windows)

**Шаг 1 — Установите Python** (один раз)

1. Откройте браузер и перейдите на [python.org/downloads](https://python.org/downloads)
2. Нажмите жёлтую кнопку «Download Python 3.x.x»
3. Запустите скачанный файл
4. **ВАЖНО:** На первом экране установщика поставьте галочку «Add Python to PATH»
5. Нажмите «Install Now» и дождитесь завершения

**Шаг 2 — Скачайте программу**

1. Перейдите на страницу: [github.com/maximpogudim-code/bloomberg-ru](https://github.com/maximpogudim-code/bloomberg-ru)
2. Нажмите зелёную кнопку **Code** → **Download ZIP**
3. Откройте папку «Загрузки», найдите скачанный ZIP-файл
4. Правый клик на файле → **Извлечь все** → выберите удобную папку

**Шаг 3 — Запустите**

1. Откройте распакованную папку
2. Дважды щёлкните на файл **START.bat**
3. При первом запуске программа установит нужные компоненты (5–10 минут) — появится много текста, это нормально
4. Когда всё готово, автоматически откроется браузер с сайтом

> Если Windows показывает предупреждение «Защитник Windows» — нажмите «Подробнее» → «Выполнить в любом случае». Это обычная программа на Python, не вирус.

## Как запустить (Mac)

**Шаг 1 — Убедитесь, что установлен Python**

Обычно Python уже есть на Mac. Если нет — скачайте с [python.org/downloads](https://python.org/downloads) (кнопка «Download Python 3.x.x» для macOS).

**Шаг 2 — Скачайте программу**

1. Перейдите на страницу: [github.com/maximpogudim-code/bloomberg-ru](https://github.com/maximpogudim-code/bloomberg-ru)
2. Нажмите зелёную кнопку **Code** → **Download ZIP**
3. Откройте папку «Загрузки», дважды щёлкните на ZIP — он распакуется в папку рядом

**Шаг 3 — Запустите**

1. Откройте распакованную папку
2. Дважды щёлкните на файл **START.command**
3. Если macOS блокирует запуск: **правый клик** на файл → **Открыть** → в диалоге нажмите **Открыть**
4. Откроется чёрное окно терминала — при первом запуске оно установит компоненты (5–10 минут)
5. Когда всё готово, автоматически откроется браузер с сайтом

> Не закрывайте чёрное окно — оно держит программу запущенной. Чтобы выключить сайт, просто закройте это окно.

## Если что-то не работает

**Браузер не открылся автоматически**
Откройте браузер вручную и введите в адресной строке: `http://localhost:8080`

**На Windows: «Python не найден»**
При установке Python не была поставлена галочка «Add Python to PATH». Удалите Python через «Программы и компоненты» и установите заново, не забыв про галочку. Либо перезагрузите компьютер после установки.

**На Mac: «Permission denied» или «не удаётся открыть»**
Откройте программу «Терминал» (Spotlight → Terminal), перетащите файл START.command в окно терминала, нажмите Enter. Либо выполните команду: `chmod +x ~/Downloads/bloomberg-ru-main/START.command`

**Сайт открылся, но новости не переводятся**
Перевод работает через интернет. Проверьте подключение к сети. Если проблема остаётся — перезапустите START.command/START.bat.

**Порт занят / «Address already in use»**
Скрипт запуска автоматически освобождает порт. Если это не помогло — перезагрузите компьютер и запустите снова.

## Для разработчиков

### Архитектура

| Компонент | Описание |
|-----------|----------|
| `app.py` | FastAPI-приложение, главный маршрутизатор |
| `dashboard.py` | Сбор рыночных данных (yfinance) и новостей |
| `translator.py` | Движок перевода: Google (бесплатно) / Claude / Groq |
| `proxy.py` | Проксирование Bloomberg-статей через httpx |
| `live_audio.py` | Транскрипция Bloomberg TV через faster-whisper |
| `cache.py` | Дисковый кэш (diskcache) |

### Эндпоинты

| Путь | Метод | Описание |
|------|-------|----------|
| `/` | GET | Главная страница (дашборд) |
| `/health` | GET | Проверка работоспособности |
| `/api/market` | GET | Рыночные котировки (live) |
| `/api/market/history` | GET | История котировок |
| `/api/quote` | GET | Котировка одного тикера |
| `/api/news` | GET | Переведённые новости |
| `/api/translate-text` | GET | Перевод произвольного текста |
| `/api/ai-brief` | GET | AI-сводка рынка |
| `/api/fear-greed` | GET | Индекс страха и жадности |
| `/api/live-transcript` | GET | Транскрипция Bloomberg TV |
| `/{path}` | GET | Прокси-перевод статей Bloomberg |

### Опции через .env

Скопируйте `.env.example` в `.env` и при необходимости задайте:

```
# Ключи для улучшенного перевода (необязательно — без них работает Google)
ANTHROPIC_API_KEY=sk-ant-...   # Перевод через Claude (качественнее)
GROQ_API_KEY=gsk_...           # Перевод через Groq (быстрее)

# Настройки
TARGET_LANG=ru                 # Язык перевода
BLOOMBERG_BASE=https://www.bloomberg.com
CACHE_PAGE_TTL=14400           # Кэш страниц (сек), по умолчанию 4 часа
CACHE_TEXT_TTL=3600            # Кэш текстов (сек), по умолчанию 1 час
```

Без API-ключей перевод работает через бесплатный Google Translate (deep-translator).

### Запуск для разработки

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium        # Необязательно, для полных статей
uvicorn app:app --host 127.0.0.1 --port 8080 --reload
```

Сайт: http://localhost:8080
