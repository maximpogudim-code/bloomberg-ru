Bloomberg Terminal на русском

Финансовые новости и котировки Bloomberg с автоматическим переводом на русский язык. Работает на вашем компьютере, бесплатно.

Скачать (ZIP)
Версия для Windows и Mac

💻 Запуск на Windows

  1. Установите Python (один раз): зайдите на python.org/downloads, скачайте и запустите установщик. Обязательно поставьте галочку «Add Python to PATH».
  2. Нажмите кнопку «Скачать (ZIP)» выше, распакуйте архив в удобную папку (правый клик → «Извлечь все»).
  3. Откройте распакованную папку, дважды щёлкните START.bat.
  4. При первом запуске программа установит компоненты — это займёт 5–10 минут. Потом автоматически откроется браузер.
Если Windows предупреждает о запуске — нажмите «Подробнее» → «Выполнить в любом случае».

🍎 Запуск на Mac

  1. Нажмите кнопку «Скачать (ZIP)» выше, распакуйте архив (двойной клик на ZIP-файл).
  2. Откройте распакованную папку, дважды щёлкните START.command.
  3. Если macOS блокирует файл: правый клик на START.command → Открыть → в диалоге нажмите Открыть.
  4. Откроется окно с текстом. При первом запуске подождите 5–10 минут. Потом автоматически откроется браузер.
Не закрывайте появившееся чёрное окно — оно держит программу запущенной. Чтобы выключить, просто закройте его.

Если что-то не работает

  1. Браузер не открылся — введите вручную в адресной строке: http://localhost:8080
  2. «Python не найден» на Windows — при установке Python не была поставлена галочка «Add Python to PATH». Переустановите Python с этой галочкой.
  3. «Не удаётся открыть» на Mac — сделайте правый клик → Открыть вместо двойного клика.
  4. Новости не переводятся — проверьте подключение к интернету и перезапустите START.command / START.bat.
